A realidade aumentada abre no celular (iPhone ou Android). Neste aparelho dá para girar o modelo acima. Para ver no espaço, abra esta página no celular pelo código QR abaixo.

O Android não abriu a realidade aumentada. Confira se o app Google Play Services para RA está instalado e atualizado (Play Store) e tente de novo.

Como usar na visita
  1. Escolha o modelo e as cores. Espere o modelo aparecer acima.
  2. Toque em Ver no espaço — tamanho real. Aponte o celular para o chão e mova devagar até o brinquedão aparecer.
  3. Se o brinquedão aparecer "em cima" de você, dê alguns passos para trás: ele tem o tamanho de verdade.
  4. Para mostrar numa mesa, use miniatura (1:10): o de 6 m fica com 60 cm.
  5. O tamanho fica travado (não dá para aumentar com os dedos), para não enganar a medida.
